## ✨ 作品地图（模块化入口）

> 想要酷炫感？这里像游戏内的“传送门”，每个模块直达不同套路：

- 🕹️ **Game Jam / 原型场**：快节奏的创意关卡与玩法实验，迭代速度像冲刺跑。
- 🛠️ **开发者工具台**：编辑器小插件、批量导入脚本、自动化管线，帮团队省下大量重复操作。
- 🌌 **Shader & VFX 实验室**：屏幕空间特效、粒子秀、风格化描边，偏好可视化参数与小型素材库。
- 🧠 **玩法系统库**：状态机、输入映射、AI 小脑（行为树/黑板雏形），强调可复用和可组合。
- 🎼 **音画节奏区**：输入反馈、触感与节奏同步的小玩具，让操作更“有手感”。

## 🧭 快速导航

- 📂 「项目总览」：按玩法类型和技术栈分组的仓库清单，方便速览。
- 🧩 「模块化示例」：常用组件的最小可复用样例（如脚本化关卡、可热插拔的技能节点）。
- 🎨 「视觉实验」：后处理链路、材质参数预设、调色 LUT，附使用说明。
- 🔧 「工具下载」：工作流脚本、编辑器扩展，常见 IDE/引擎的安装与使用提示。

## 🚀 当前关注
